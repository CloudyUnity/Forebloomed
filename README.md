A massive action-roguelike game released for Steam, Itch.io and CrazyGames  
Positve on Steam  
9.1/10 on CrazyGames  
4.3/5 on Itch.io  

For information about the game itself, see below:  
https://store.steampowered.com/app/2589990/Forebloomed_Evergreen_Edition/  
https://cloudy2021.itch.io/forebloomed  

If you wish to play an older version of the game for free, see below:  
https://www.crazygames.com/game/forebloomed  

Developed in Unity using C# and ShaderGraph  
Played by over 100,000 players  
I worked on the programming, art, sfx, marketing and community management  
I worked alongside a composer in exchange for a cut of the profits. We also made a steam release of the soundtrack
